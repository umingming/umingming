## About Me

- Vue와 React를 오가며 웹 화면을 만드는 일을 좋아합니다.
- 복잡한 기능도 사용자가 편하게 느끼는 흐름으로 정리하는 데 관심이 있습니다.
- 작은 프로젝트라도 기록하고 다듬으면서 꾸준히 성장하는 개발을 지향합니다.
